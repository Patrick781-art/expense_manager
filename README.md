\# Expense Manager



A simple Python command-line application for managing expenses.



\## Features



\- Add expenses

\- View all expenses

\- Calculate total spending

\- Validate expense amounts

\- Save and load expenses using JSON

\- Automated tests using pytest



\## Technologies



\- Python

\- JSON

\- Pytest

\- Git and GitHub
